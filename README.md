
# 🚛 Addis Path Trailers Landing Page

## Overview

This is a **beautifully designed landing page** for a Trailer rental business based in Atlanta, Georgia, built using **Next Js**. It showcases the business' offerings, ambiance, and contact details, providing a seamless user experience. The design is modern, responsive, and visually appealing, ensuring that it looks great on all devices.

**Live Demo**: Check it out here: [Addis Path Trailers Landing Page ](https://addispathtrailers.com/)

## ✨ Features

- **Minimalist Hero Section**: Highlights AddisPath’s vision with strong CTAs.
- **Responsive Layout**: Seamlessly adapts across mobile, tablet, and desktop devices.
- **Smooth Animations**: Utilizes subtle motion to create an engaging user experience.
- **Brand Showcase**: Introduces AddisPath with a modern and elegant aesthetic.
- **Accessible Design**: Built with accessibility and readability in mind.
- **Mobile-First Approach**: Optimized for fast loading and smooth scrolling on phones.
  
## 🛠️ Built With

- **Next.js**: React framework for SSR and static site generation.
- **Tailwind CSS**: Utility-first framework for rapid and custom styling.
- **Shadcn/UI**: Headless UI components for better accessibility and customization.
- **Framer Motion** *(optional)*: For fluid animations and transitions.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your system.

### Installation

1. Clone the repository:
   ```bash
   https://github.com/JustMikk/addis-path-trailers.git
   ```

2. Navigate to the project directory:
   ```bash
   cd addis-path-trailers
   ```

3. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Project

To start the development server, run:

```bash
npm start
```

The application will be running at `http://localhost:3000`.

### Building for Production

To build the app for production, run:

```bash
npm run build
```
